当前 Hybro Timeline — 用户发送后的状态流

当前流程（问题标注）
用户发送 "Can you give me an excel"
1. 用户消息出现 → 右对齐气泡 ✅
2. 等待期 — 空白 ⚠️ 没有任何加载/thinking 指示
3. Event rail 出现 ⚠️ 突然跳出时间戳列表，无动画过渡
4. Summary 块 + Agent Results ⚠️ Summary 和 Results 重复显示同一 agent 内容
5. HITL 状态卡住 ⚠️ 回答后仍显示 "Awaiting input..."

Cursor 风格 — Agent Workflow 状态流

Cursor 的处理流程
用户发送请求
1. 即时反馈 ✅ 立刻出现 "thinking..." 或 spinner
2. 渐进式展示 ✅ Agent 名出现 → 内容流式打字 → 完成
3. 无冗余信息 ✅ 没有 summary 重复，每条信息只出现一次
4. 状态实时更新 ✅ 交互完成后立即更新状态标签
5. 紧凑事件轨迹 ✅ 工具调用/文件操作作为内联 chip，不占大量空间
