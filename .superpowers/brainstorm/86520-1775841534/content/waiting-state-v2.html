关键设计细节

Cursor 风格要点
✓
无背景色块
Agent 行直接嵌入内容流，用细分割线分隔，不用卡片
✓
状态在右侧，不跟在名字后面
Thinking / Generating / ✓ 完成 — 对齐到行尾
✓
内容直接在 agent 名下方展开
左侧 18px padding 与圆点对齐，内容无额外容器
✓
脉冲动画而非 spinner
圆点外圈 ping 效果表示活跃，比旋转 spinner 更轻量
✓
HITL 是唯一有背景的元素
需要用户操作的内容用微弱边框突出，其余全部无框
