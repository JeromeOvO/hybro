你觉得 Supervisor 状态应该怎么展示？

A

Supervisor 头部栏

在 agent 列表上方显示 Supervisor 图标 + 阶段 shimmer（"Step 2 of 3 · Dispatching agents"），完成后变为统计信息（"3 agents · 12.4s"）

B

Synthesis 结果优先显示

Supervisor 汇总（Summary Agent）完成后作为主要内容显示，各 agent 独立结果折叠为"Show individual responses"

C

HITL 不显示为 agent

supervisor_hitl 的提问不作为 "Question & Answer" agent 行，而是作为独立的提问卡片（问号图标 + 黄色 shimmer），归属到 turn 级别而非某个 agent

D

和普通模式保持一致

不做 Supervisor 特殊处理，所有消息（包括 Summary Agent）都按普通 agent 行显示
