# Security Policy

Hybro AI takes security seriously. We appreciate the work of security researchers and the community in helping us keep our software safe and secure.

---

## Supported Versions

We provide security updates for the following versions of Hybro AI:

| Version | Supported |
| ------- | ------------------ |
| `main` branch (latest release) | :white_check_mark: |
| `< 0.2.0` | :x: |

---

## Reporting a Vulnerability

**Please do not report security vulnerabilities through public GitHub issues.**

Instead, report suspected vulnerabilities confidentially by emailing our team:

- **Email**: [security@hybro.ai](mailto:security@hybro.ai)

Please include as much of the following information as possible to help us understand and resolve the issue quickly:

- Type of issue (e.g., buffer overflow, SQL injection, unauthorized access, cross-site scripting).
- Full path(s) or component(s) affected.
- Detailed steps to reproduce the issue.
- Proof of concept or exploit code, if available.
- Any potential impact or mitigation thoughts.

---

## Preferred Response Process

1. **Acknowledgement**: We will acknowledge receipt of your report within 48 hours.
2. **Assessment**: Our team will evaluate the issue and determine its severity.
3. **Fix & Patch**: We will develop and test a fix as quickly as possible.
4. **Public Disclosure**: Once a patch is released, we will credit you (unless you prefer anonymity) in the release notes or security advisory.

Thank you for helping keep Hybro AI safe!
